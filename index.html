VIP Notes: MongoDB & JSON Filters Core Concepts
KEY OPERATORS & SYNTAX (Based on Lecture 2)
✦
Comparison Operators: $gt (Greater Than), $gte (Greater Than or Equal), $lt (Less Than), $lte (Less Than or Equal), $ne (Not Equal), $eq (Equal - usually implicit).
✦
Logical Operators: $and (All conditions must match - implicit if separated by comma), $or (At least one condition matches), $not (Negates a condition).
✦
Array & Element Operators: $in (Matches any value in an array), $nin (Matches none of the values in an array), $all (Array field must contain all specified elements), $exists (Checks if a field exists).
✦
JSON Structure: Documents are enclosed in {}. Arrays are enclosed in []. Keys (fields) must be strings enclosed in double quotes "". Values can be strings, numbers, booleans, arrays, objects, or null.
✦
Range Queries: Can be combined in one object: {"salary": {"$gte": 19000, "$lte": 79000}} or using $and: {"$and": [{"salary": {"$gte": 19000}}, {"salary": {"$lte": 79000}}]}.
Part I: Multiple Choice Questions (20 Questions)
Q1

Write a JSON filter to retrieve employees with: fname="Kim" and gender="F"

اكتب فلتر JSON لاسترجاع الموظفين بالشروط التالية: الاسم الأول = "Kim" و الجنس = "F"

A) {"$or": [{"fname": "Kim"}, {"gender": "F"}]}
B) {"fname": "Kim", "gender": "F"}
C) {"$and": [{"fname": "Kim"}, {"gender": "F"}]}
D) {"fname": {"$eq": "Kim"}, "gender": {"$eq": "F"}}
✓ Correct Answer: C

Rationale: The $and operator explicitly requires all conditions in the array to be true. (Note: Option B is also valid as an implicit AND, but $and is the explicit logical operator for this condition).

السبب: المعامل $and يتطلب بشكل صريح أن تكون جميع الشروط داخل المصفوفة صحيحة. (ملاحظة: الخيار B صحيح أيضاً كعملية AND ضمنية، ولكن $and هو المعامل المنطقي الصريح لهذا الشرط).

Q2

Write a JSON filter for: salary >= 79000 or gender="F"

اكتب فلتر JSON للشرط التالي: الراتب أكبر من أو يساوي 79000 أو الجنس = "F"

A) {"$and": [{"salary": {"$gte": 79000}}, {"gender": "F"}]}
B) {"$or": [{"salary": {"$gte": 79000}}, {"gender": "F"}]}
C) {"salary": {"$gte": 79000}, "gender": "F"}
D) {"salary": {"$or": 79000}, "gender": "F"}
✓ Correct Answer: B

Rationale: The $or operator matches documents where at least one of the conditions in the array is true.

السبب: المعامل $or يطابق المستندات التي يتحقق فيها شرط واحد على الأقل من الشروط الموجودة في المصفوفة.

Q3

Write a JSON filter for: dno != 8 and gender="F"

اكتب فلتر JSON للشرط التالي: رقم القسم لا يساوي 8 و الجنس = "F"

A) {"$and": [{"dno": {"$ne": 8}}, {"gender": "F"}]}
B) {"$or": [{"dno": {"$ne": 8}}, {"gender": "F"}]}
C) {"dno": {"$not": 8}, "gender": "F"}
D) {"dno": {"$neq": 8}, "gender": "F"}
✓ Correct Answer: A

Rationale: $ne means "not equal". Since both conditions must be satisfied, we use $and.

السبب: $ne تعني "لا يساوي". وبما أنه يجب تحقيق كلا الشرطين معاً، نستخدم $and.

Q4

Write a JSON filter for: dno is in {5,6}

اكتب فلتر JSON للشرط التالي: رقم القسم موجود ضمن المجموعة {5,6}

A) {"dno": {"$all": [5, 6]}}
B) {"dno": {"$or": [5, 6]}}
C) {"dno": {"$eq": [5, 6]}}
D) {"dno": {"$in": [5, 6]}}
✓ Correct Answer: D

Rationale: The $in operator matches any document where the field value equals any value in the specified array.

السبب: المعامل $in يطابق أي مستند تكون فيه قيمة الحقل مساوية لأي قيمة في المصفوفة المحددة.

Q5

Write a JSON filter for: salary is not in {79000, 19000}

اكتب فلتر JSON للشرط التالي: الراتب غير موجود ضمن المجموعة {79000, 19000}

A) {"salary": {"$not": [79000, 19000]}}
B) {"salary": {"$ne": [79000, 19000]}}
C) {"salary": {"$nin": [79000, 19000]}}
D) {"salary": {"$notin": [79000, 19000]}}
✓ Correct Answer: C

Rationale: $nin (Not In) matches documents where the field value is not equal to any value in the specified array.

السبب: $nin (ليس ضمن) يطابق المستندات التي لا تكون فيها قيمة الحقل مساوية لأي قيمة في المصفوفة المحددة.

E4

Explain the difference between the $in and $all operators in MongoDB, providing an example for each.

اشرح الفرق بين المعاملين $in و $all في MongoDB، مع إعطاء مثال لكل منهما.

  • $in: Matches documents where the field value equals ANY of the values in the specified array. It acts like a logical OR for array elements.
    Example: {"dno": {"$in": [5, 6]}} finds documents where dno is 5 OR 6.
  • $all: Matches documents where the array field contains ALL the specified elements. It acts like a logical AND for array elements.
    Example: {"class": {"$all": ["cs", "it"]}} finds documents where the class array contains BOTH "cs" and "it".
  • $in (ضمن): يطابق المستندات التي تكون فيها قيمة الحقل مساوية لأي من القيم في المصفوفة المحددة. يعمل كعملية OR منطقية لعناصر المصفوفة.
    مثال: {"dno": {"$in": [5, 6]}} يجد المستندات التي يكون فيها dno يساوي 5 أو 6.
  • $all (الكل): يطابق المستندات التي يحتوي فيها حقل المصفوفة على جميع العناصر المحددة. يعمل كعملية AND منطقية لعناصر المصفوفة.
    مثال: {"class": {"$all": ["cs", "it"]}} يجد المستندات التي تحتوي فيها مصفوفة class على كل من "cs" و "it".

  "salary": { "$gte": 19000, "$lte": 79000 },
  "dno": 6

Method 2 (Explicit $and):

E7

Explain the purpose of the $exists operator and provide a query to find documents where the "end_date" field does not exist.

اشرح الغرض من المعامل $exists وقدم استعلاماً للعثور على المستندات التي لا يوجد فيها الحقل "end_date".

  • Purpose: The $exists operator is used to check for the presence (or absence) of a field in a document. It takes a boolean value (true or false).
  • Query: {"end_date": {"$exists": false}} will return all documents that do not have the "end_date" field.
  • الغرض: يُستخدم المعامل $exists للتحقق من وجود (أو عدم وجود) حقل معين في مستند ما. يأخذ قيمة منطقية (true أو false).
  • الاستعلام: {"end_date": {"$exists": false}} سيعيد جميع المستندات التي لا تحتوي على الحقل "end_date".
E8

Translate the following logical condition into a MongoDB JSON filter: "The department number must not be 8 AND the gender must be F."

ترجم الشرط المنطقي التالي إلى فلتر JSON في MongoDB: "رقم القسم يجب ألا يكون 8 و الجنس يجب أن يكون F".

{
  "$and": [
    { "dno": { "$ne": 8 } },
    { "gender": "F" }
  ]
}

(Note: It can also be written implicitly as {"dno": {"$ne": 8}, "gender": "F"}).

(ملاحظة: يمكن كتابتها أيضاً بشكل ضمني كـ {"dno": {"$ne": 8}, "gender": "F"}).
